# 📚 Library System

## 📝 Description / Overview
The **Library System** is a web-based project designed to manage books, students, and borrowing transactions in a library.  
It helps librarians record, track, and organize all library operations efficiently.

---

## 🎯 Objectives
- To automate book borrowing and returning processes.  
- To reduce manual errors in tracking library records.  
- To make library management faster and more accurate.  
- To store student and book data securely.

---

## ⚙️ Features / Functionality
- Add, edit, and delete book records.  
- Register new students and manage profiles.  
- Record book borrowing and return transactions.  
- Generate library activity reports.  
- Display book availability status (Available / Borrowed).
